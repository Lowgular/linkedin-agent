# activity

a member's activity page: every post, repost and comment of theirs, newest first, under the heading `All activity`

Path pattern: `^/in/[^/]+/recent-activity/`

Open: `https://www.linkedin.com/in/<slug>/recent-activity/all/`. Replace the placeholder with the member's slug or post URN.

The heading `All activity` is at the top of the main column, and each item below it is a card headed `Feed post`.
